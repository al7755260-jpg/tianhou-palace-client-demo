## Windows 客户：直接体验

1. 将整个压缩包解压到一个文件夹。
2. 双击 `启动体验.cmd`，会自动打开浏览器。
3. 体验期间保持启动窗口打开，结束后关闭该窗口。

已随包附带 Windows x64 版 Node.js，无需安装 Node、Git 或开发依赖。请使用支持图形加速的现代 Chrome / Edge。若浏览器没有自动打开，可复制启动窗口中的地址。默认地址为 `http://127.0.0.1:4210/`，端口被占用时会自动顺延。

请通过启动程序访问，不要直接双击 `site/index.html`：三维模型和工作线程需要通过本地网页服务加载。

## 体验内容

- 白天入口：粒子宫庙、轻微鼠标视差、动态船只与水面。
- 海面航图：三座天后宫放大约 45%，按最大旋转范围分隔摆放；两侧港口缩小并减少重复建筑、吊机与船只，保留生成动画、鼠标悬停和拖动互动。
- 点击宫庙进入泉州、澳门、深圳详情页，探索兴趣点；可切换昼夜、旋转和缩放。
- 海面电脑置于 ImageGen + Rodin 生成的木舟书桌上，配悬挂暖灯、水面倒影与随波轻摆；灯舟移到前景，增大官方电脑的画面占比。
- 三座宫庙的兴趣点增加星芒与柔和光晕；详情模型默认放大，并保留高瘦模型的上下边距。
- 海面生成动画在同一标签页首次进入时播放，之后直接显示完整宫庙。
- 首页和海面页的笔记本已替换为客户提供的 GX651 官方模型，使用深钛色机身、双屏与独立键盘；网页轻量模型约 1.20 MB，保留双屏、键帽与触控板细节，高精度版本同时保留。首页键盘与支架贴合地坪，夜景机身补光增强，双屏与原玻璃分层以避免移动镜头时闪烁。
- 流畅性优化：减少官方电脑的冗余细分面，直接显示入口建筑的烘焙光照纹理，减少水面采样中高处建筑的重复绘制，并缓存静态灯位置；画面分辨率和宫庙粒子数量不变。

本包已包含入口性能优化、海面清晰度恢复和详情页切换白闪修复。首页保留 3D 粒子效果，四个 Logo 的显示清晰度已调整，整站背景音乐及音乐开关已取消。帧率取决于客户设备与窗口大小。

## Git 仓库

```sh
git clone https://github.com/al7755260-jpg/tianhou-palace-client-demo.git
```

配套 `.bundle` 是此体验版本的完整 Git 仓库归档，可直接克隆：

```sh
git clone "天后宫-客户体验仓库-20260928.bundle" tianhou-palace-demo
cd tianhou-palace-demo
```

仓库保存可运行的网站成品、体验启动器和素材。它用于客户体验与静态部署；不是原始建模和开发工程。

## 静态部署 / 其他系统

将 `site/` 目录的全部内容作为网站根目录上传到静态托管服务即可。托管需使用 HTTPS，或在本机通过 localhost 访问。

macOS / Linux 或已安装 Node.js 的环境，可在此目录运行：

```sh
node preview.mjs
```

服务仅监听本机地址。资料来源链接需要联网；网站画面、模型等体验资源均随包提供。

## 文件与校验

- `site/`：已构建网页和体验资源。
- `runtime/node.exe`：Windows x64 启动运行时。
- `preview.mjs`：本地静态服务，支持音频范围请求。
- `release-manifest.json`：随包文件的 SHA-256 清单。
- `licenses/`、`THIRD_PARTY_NOTICES.md`：第三方组件说明与许可。

Windows 校验包内文件：

```bat
runtime\node.exe verify.mjs
```

本地服务绑定 127.0.0.1，不需要账户、API Key 或云服务配置。
